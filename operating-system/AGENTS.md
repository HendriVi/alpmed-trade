# Agent operating manual

Use `CLAUDE.md` (identity), `CONTEXT.md` (router), selected stage `NN_*/CONTEXT.md` (contract), and only listed references. `STATUS.md` is the persistent checkpoint. Source links belong alongside claims. Do not copy account credentials into any file; use host secrets. A public clinic directory entry is a **prospect**, not an actual buyer. A public auction listing is **unverified supply**, not available stock. A 'match' is not a committed sale. Save research to the respective `output/` folder, and live records to the deployed app through its approved admin functions. Do not create a second spreadsheet or CRM. No sending messages, purchasing equipment, publishing the site, opening escrow or incurring charges without authorization. Stage advancement must satisfy its pass criterion.
